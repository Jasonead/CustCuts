## 🚀 Overview

**Custcuts** is a high-performance, modern Windows desktop utility that simplifies workflow automation with custom global keyboard hotkeys. Instantly paste snippets, launch applications (`.exe`), open web URLs, or navigate folders using customizable key combinations.

---

## ✨ Features

- 🌙 / ☀️ **Night Mode & Day Mode**: Seamlessly switch between a sleek obsidian dark theme and a clean light mode backdrop.
- ⌨️ **Global Hotkey Listeners**: Native Win32 API hotkey binding for instant execution across any active application.
- 📋 **Clipboard Automation**: Smart text pasting with configurable clipboard restore delay.
- 🔒 **Security Passcode Lock**: Secure your dashboard configuration with a PIN/password lock and custom security question recovery.
- ⚡ **Windows Startup Integration**: Option to automatically start Custcuts when Windows logs in.
- 🗑️ **Standalone Uninstaller Executable**: Bundled `Uninstall_Custcuts.exe` utility for easy full cleanup and reinstallation.

---

## 📦 Installation & Setup

1. Download **`CustcutsSetup_v1.0.exe`** from the latest release.
2. Run the installer and follow the setup wizard.
3. Launch **Custcuts ⚡** from your Desktop or Start Menu.
4. (Optional) Run **`Uninstall_Custcuts.exe`** anytime to perform a clean uninstallation.
